# Ата жолы — проживи жизнь прадеда

Веб-игра: ты рождаешься случайным предком 1900–1935 годов на земле Казахстана и проживаешь его жизнь год за годом.
Вероятности событий — по модели на переписях и оценках историков (источники: [docs/history-data.md](docs/history-data.md)).
Языки: казахский, русский, английский. В конце — карточка для соцсетей и ссылка, которая открывает ту же жизнь.

```sh
npm install
npm run dev        # http://localhost:5350
npm test           # калибровка по историческим диапазонам, тексты, повтор ссылок, непротиворечивость жизней
npm run build      # dist/ (base /ata-zholy/ для GitHub Pages; BASE=/ для своего домена)
node tests/flow.mjs http://localhost:5350/   # полные партии в Chrome и WebKit на телефоне
```
